# MyPet

Aplicación Android para guardar identificaciones de mascotas localmente y consultar una galería de razas de perros.

## Funciones

- Registrar nombre, fecha de nacimiento, especie, raza, sexo, color, responsable y microchip.
- Crear un ID único para cada mascota y guardar sus datos en Room.
- Consultar fotos y nombres de razas desde Dog API, sin clave ni código postal.

La galería muestra razas y fotografías de referencia; no contiene perros individuales disponibles para adopción. Dog API publica sus imágenes con créditos y licencias en los datos de cada raza, que la app muestra en las tarjetas.
